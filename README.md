## забавный self-hosted проект для создания мини-игры на стримах
### с интеграцией [api spworlds](https://github.com/sp-worlds/api-docs) для отслеживания получаемых переводов

все переменные (загадываемое слово, время, отображаемая карта) задаются в аргументах ссылки, для удобства пользования в OBS
